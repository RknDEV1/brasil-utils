# Brasil Utils

Utilitários **Swift** simples para dados brasileiros.

> English: [README.md](README.md)

## O que tem

- Formatação de telefone (DDD)
- CEP
- Validação e formatação de CPF
- Moeda em R$

## Instalação

```swift
.package(url: "https://github.com/RknDEV1/brasil-utils.git", branch: "main")
```
